# フリップ・クレスト (Flip Crest)

リバーシの盤にキャラクターの駒を置き、挟んで裏返しながら相手の HP を削る対戦ゲームです。macOS 版と Windows 版（64 ビット）を無料でダウンロードできます。

## ダウンロード

- **[ダウンロードページ](https://seiryu1996.github.io/flip-crest-releases/)**（遊び方・インストールの方法・更新内容）
- [Releases](https://github.com/Seiryu1996/flip-crest-releases/releases)（版ごとの zip と SHA-256）

## インストール

- **macOS**: zip を開き、`FlipCrest.app` をアプリケーションフォルダに入れます。はじめて開く時は、アプリを右クリック →「開く」を選んでください（Apple の公証をしていないため）。
- **Windows**: zip を右クリック →「すべて展開」で展開し、`FlipCrest` フォルダの中の `FlipCrest.exe` を開きます。「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を選んでください（コード署名をしていないため）。
